## Comparable measurements

Retained Sprint 39 C1 service rates are **119.95–120.18 output tok/s**, with median request latency **8.50–8.52 seconds**. C2 is **172.75–172.98 aggregate tok/s**, with median individual latency **11.76–11.87 seconds**. These rates include prefill and HTTP completion across both GPUs. They are neither per-card rates nor isolated decode rates. C1/C2 paths and verifier counts differ.

The recent C2 metadata BA control/candidate medians were 174.78/176.38 aggregate tok/s and 11.72/11.61 seconds individual latency. Together with AB, the result misses the 2% selection threshold. All six timed C1 output/work pairs matched in each order; all six timed C2 pairs differed. Four unique short-answer oracles and repeated code checks do not establish sampling-distribution equivalence.

For the two roughly 26K-input prefill tasks, current 2K chunks measured TTFT 9.2604/9.2811 seconds; the improved 4K profile measured 9.5214/9.5324 seconds. Per-rank peak allocated/reserved bytes increased from 21,513,001,984/21,913,141,248 to 21,931,351,040/22,420,652,032. Outputs and verifier work differ; no decode-throughput gain is inferred.

Static width four added 32.90%/12.14% HTTP time at short C1/C2 and 8.44%/2.85% at long C1/C2. All timed requests emitted 64 tokens. Short output histories differed; long histories matched, but actual verifier cycles/rows differed. Instrumentation is included, TTFT/ITL are not separated, and the values are not a replacement for the selected service-rate benchmark. Both native greedy and sampled routes were observed; statistical distribution correctness was not established.

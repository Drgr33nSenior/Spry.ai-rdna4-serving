## Installed-source findings

A bounded, read-only workstation inspection retained 13 source files using the
declared Python 3.14.4. Nine existing file pins matched. Four newly inspected
dependency files now have observed hashes; they still need to enter the final
owner source manifest. No frameworks were imported and no GPU work ran.

The installed profiler synchronizes the device before disabling Kineto at stop.
The diagnostic therefore continues to exclude profiled latency from scoring.
Plain `.json` export reaches the supplied path directly; the separate Python
gzip path would create an intermediate file and is not used.

The SGLang source connects the observed verify and correct-draft counters to the
HTTP metadata. Its visible output count uses the stop-trimmed output IDs.
These source checks support the join contract; live equality remains unmeasured.
Both scheduler methods have two decorator layers. The new callable check
authenticates their compiled code, closure links, labels and original methods.
It compiles complete source files without executing those modules.

## Publication and failure handling

`shared_owner.py` publishes the digests returned by the observer. The collector
cannot manufacture missing producer pins by hashing whatever files remain.
HTTP evidence receives a separate receipt bound to the actual start and menu.
Replay requires both ranks and retains the existing source, wire, quality and
independent-release requirements.

Worker receipts publish when the frozen 30-request menu finishes, before the
worker returns or the owner terminates it. Callback failures also publish
before the native scheduler can catch the error and signal its parent. Hooks
are restored once, and a native exception survives a cleanup or publication
exception. A parent barrier waits at most five seconds, inside the existing
deadline, for both completed rank receipts before teardown.

An unresolved profiler stop now ends the worker path. The installed source can
raise before disabling profiling, so continuing model batches would leave its
state uncertain. The code does not retry stop. An existing model exception is
preserved, and the eventual owner must retain and authenticate failed closeout.

The collector checks a closed filename set, file and aggregate byte bounds,
regular files and link restrictions. Complete replay checks the original
producer receipts, HTTP evidence, core records and seven fixed capture windows.
Collection alone makes no semantic-success or resource-release claim.

## Verification

All **51 focused tests pass** on local Python 3.11 and native Python 3.14.4:
six callable-binding, sixteen owner, nineteen capture and ten readout tests.
The native test ran in the existing namespace sandbox with GPU devices absent,
no framework imports, no network and bounded disposable storage. The required
43-check public preflight passed. Two mutations demonstrate that the tests fail
if menu-boundary publication or unresolved-stop refusal is removed.

The first file-inspection attempt used the transport bootstrap interpreter and
stopped at its exact-version assertion before reading requested runtime files.
That failure is retained. The corrected inspection used the established rootfs
Python path. Both transport processes exited and were reaped cleanly.

Framework objects, worker lifetimes and trace events in the tests remain
synthetic. Compiling installed method bodies establishes source compatibility;
it does not run those methods or qualify a live worker.

# Sprint 33: 64K long-context SRE screen

Two repeated starts completed 14 normal-stop responses at a 65,536-token context setting. All seven full output-ID and verifier-cycle pairs matched. The six long cases in each start used 59,999 input tokens; actual outputs were 567–849 tokens, below the 4,096-token cap. This did not exercise the full context-plus-output boundary.

The frozen literal and factual graders each scored **10 of 12** long responses; both gates failed. Both `runbook-50` responses supplied the correct action-order words as a string, while the oracle required an array. The question asked for two verbs but did not explicitly specify an array. The descriptive format audit preserves both failures; it adds no normalization and performs no regrade. The Sprint 32 owner exception does not cover these Sprint 33 failures. This screen does not establish general long-context quality. Independent review approved the conservative closeout.

Each start used one short warmup and six synthetic SRE cases across two task families and three evidence layouts. The selected experimental profile retained FP8 weights, BF16 target and draft KV, b101 W4 and aligned ring-fold, with 19 usable/20 physical recurrent slots. The split-KV adapter's 64K eligibility guard was captured on both ranks in both starts, with 524,288 index elements per rank. The numerical kernel, installed runtime and production defaults did not change.

The native command took 715.11 seconds. Long-request non-streaming client elapsed times ranged from 35.81 to 37.87 seconds, including prefill and generation; time to first token and pure decode rate were not measured. These are not a throughput comparison. Startup allocation was 22,433,668,608 bytes per card and driver-reported free memory was 10,462,691,328 bytes per card; these are not whole-workload GPU peaks. Host peaks were 27,755,708,416 and 21,402,025,984 bytes under a 40,802,189,312-byte limit, with zero recorded memory events. Independent release passed.

The optional [64K guard patch](../patches/sglang-dflash-splitkv-context64.patch) applies to the public prototype without installing it. It retains the public mtp-only A/B arm policy; the private repeated-profile screen enabled both arms. The adapter bytes otherwise match after normalizing that policy. The [provenance record](../provenance/SPRINT33-LONG-CONTEXT64-20261023.json) binds the source and readout evidence.

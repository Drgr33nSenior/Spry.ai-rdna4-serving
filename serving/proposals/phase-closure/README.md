# Selected phase closure

This proposal removes 16 inactive phase-marker names from the paired HTTP
package and migrates their consumers. It removes 285 Python lines. The selected
phase remains `sprint01-paired-serving` with DFlash8, aligned GDN, BF16 caches,
the same requests, fixed pools and startup observability requirements.

The contract still validates settings before returning phase-specific results.
Retired stream, generated-history and closure-comparison entry points refuse
execution. Unexpected HIP component records still fail startup admission.
Historical packages retain their own source and readers.

This increment changes nine runtime or evidence modules and two protected
conditions in the owner and controller. It preserves the other seven protected
files, kernels, shared head, packed projection, replay adapter and all launch
arguments except derived source pins. The package retains 79 members under the
existing 80-member ceiling. It introduces no witness-format change.

See [PROPOSAL.json](PROPOSAL.json) for exact source pins and
[VERIFICATION.json](VERIFICATION.json) for observed checks and remaining gates.
Source and fixture checks cannot establish native tensor behavior, GPU replay,
model quality or measured memory recovery. The complete cleanup still requires
shared-helper migration and fresh approved native qualification.

# Final native qualification preparation

The final campaign preparer accepts an explicit run directory and a separate
instrumented qualification flag. Both campaign arms use the same mode. The
default comparison still requires production mode. Instrumented qualification
requires an explicit matched baseline and rejects changed requests, models,
kernels, pools or execution contracts. Its results are marked as qualification
and must not be used as production timing evidence.

The private preparation contains sealed pre-memory and final source authors for
both modes. Production uses decode logging interval 100; instrumentation uses
interval 1. Each pair has exact 78/79-member archives under the unchanged
80-member and 16 MiB ceilings. The same final runtime and protected source bytes
are used in both modes. The full protected review also records the delta from
the last executed campaign, separate from the measurement comparison delta.

A sealed GPU-free CPU tensor envelope precedes GPU adoption. It checks real CPU
storage and version semantics with stub ops and explicit device-admission
substitutes. It does not prove native quantizer arithmetic or recovered memory.

Observed checks: 999 Python tests across 81 public suites plus C++ sanitizers;
270 target CPython 3.14.7 source checks without native imports, network or GPU
work; six complete campaign integration checks per mode; two local CPU envelope
refusal and namespace checks. All 456 Python and patch files in the native
snapshot match the final source. No runtime or protected source changed in this
preparation increment. See [VERIFICATION.json](VERIFICATION.json).

The next step requires exact one-use approval for the CPU tensor envelope and,
only if it passes, one instrumented final candidate campaign. Later production
campaigns require separate approvals. Greedy token identity, selected quality,
startup byte proofs, BDF memory evidence and final retained replay remain open.
The cleanup is not complete and no execution allowance remains. No memory or
performance improvement has been measured for the final source.
